# Real vs AI-Generated Image — Experiment Workspace

Research/experiment repository for preprocessing image data and training a classifier to distinguish **real images from AI-generated images**.

## Published artifacts

```text
Training.ipynb
cvpr-realsynthx-(preprocessing).ipynb
Real And AI images(processed).rar
```

- `cvpr-realsynthx-(preprocessing).ipynb` contains preprocessing work.
- `Training.ipynb` contains the training workflow.
- `Real And AI images(processed).rar` is a packaged processed-data artifact.

## Status

This repository currently functions as an **experiment workspace**, not a packaged application. Model architecture, final metrics, environment requirements, and a reproducible inference script should be documented from the executed notebook outputs before making performance claims.

## Reproducibility note

The processed archive is large. A future cleanup should move large datasets/artifacts to an appropriate dataset or release host and keep GitHub focused on code, configuration, documentation, and compact results.
